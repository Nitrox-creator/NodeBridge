# NodeBridge
#Français
ESP Control est un projet de domotique DIY basé sur les microcontrôleurs ESP8266 et ESP32. Il permet de contrôler des composants électroniques, de récupérer des données de capteurs et de communiquer avec d'autres systèmes via le réseau.

Deux versions du projet sont disponibles :

## Version ESP8266

Version légère destinée aux cartes comme NodeMCU ESP8266 ou Wemos D1 mini.

Fonctionnalités :

* Contrôle des GPIO
* Lecture de capteurs analogiques et numériques
* Connexion Wi-Fi
* Interface de contrôle
* Compatible avec des projets simples de domotique

## Version ESP32

Version plus avancée profitant des capacités supplémentaires de l'ESP32.

Fonctionnalités :

* Gestion de plusieurs capteurs
* Communication MQTT
* Envoi de données au format JSON
* Intégration possible avec des plateformes domotiques
* Plus de ressources pour des projets complexes

## Matériel compatible

* ESP8266 (NodeMCU, Wemos D1 mini)
* ESP32
* LEDs
* Boutons
* Capteurs de température
* Capteurs analogiques
* Modules électroniques compatibles Arduino

## Objectif

Créer une base de domotique personnalisable permettant de découvrir l'électronique, la programmation embarquée et l'IoT.

Le projet est développé en Arduino C++.

# NodeBridge
#English

ESP Control is a DIY home automation project based on ESP8266 and ESP32 microcontrollers. It allows you to control electronic components, retrieve sensor data, and communicate with other systems over a network.

Two versions of the project are available:

## ESP8266 Version

A lightweight version designed for boards like the NodeMCU ESP8266 or Wemos D1 mini.

Features:

* GPIO control
* Analog and digital sensor reading
* Wi-Fi connectivity
* Control interface
* Compatible with simple home automation projects

## ESP32 Version

A more advanced version that takes advantage of the additional capabilities of the ESP32.

Features:

* Management of multiple sensors
* MQTT communication
* Sending data in JSON format
* Integration with home automation platforms
* More resources for complex projects

## Compatible Hardware

* ESP8266 (NodeMCU, Wemos D1 mini)
* ESP32
* LEDs
* Buttons
* Temperature sensors
* Analog sensors
* Arduino-compatible electronic modules

## Objective

To create a customizable home automation platform for exploring electronics, embedded programming, and the IoT.

The project is developed in Arduino C++.
